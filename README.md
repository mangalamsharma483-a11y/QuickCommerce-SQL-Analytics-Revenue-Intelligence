# QuickCommerce SQL Analytics & Revenue Intelligence

A SQL Server-based analytics project built using Quick Commerce product data to generate business insights into **product pricing, discounts, inventory availability, cost per gram, and potential revenue**.

## Tech Stack

* SQL Server
* T-SQL
* SSMS
* Power BI
* Git & GitHub

## Key Features

* Dynamic SQL for analyzing multiple product datasets
* Product discount and pricing analysis
* Out-of-stock rate analysis
* Cost-per-gram analysis
* Potential revenue estimation
* Temporary result tables for structured analysis
* Aggregate functions and business calculations
* CASE expressions and window functions
* Metadata-driven queries using `INFORMATION_SCHEMA`
* Ranking and comparative analysis

## Business Insights

The project helps identify:

* Products with the highest discounts
* Products offering better value per gram
* Categories/products with high stock-out rates
* Datasets with higher potential revenue
* Pricing and inventory patterns

## Objective

The objective is to transform raw Quick Commerce data into meaningful business insights using advanced SQL Server and T-SQL techniques.
